\# Supermarket Sales Data Visualization



\## Project Overview



This project focuses on analyzing and visualizing supermarket sales data using Python. Different charts are used to explore sales distribution, product performance, branch sales, customer behavior, payment methods, and relationships between numerical variables.



\## Objectives



\- Understand the supermarket sales dataset.

\- Visualize sales patterns using different charts.

\- Compare sales across product lines and branches.

\- Analyze customer ratings, customer types, and payment methods.

\- Identify useful findings from the data.



\## Dataset



The project uses `supermarket\_sales.csv`, which contains 1,000 records and 17 columns related to supermarket transactions.



\## Tools and Technologies



\- Python

\- Jupyter Notebook

\- Pandas

\- Matplotlib

\- Seaborn



\## Visualizations



The notebook includes the following visualizations:



1\. Distribution of total sales

2\. Total sales by product line

3\. Total sales by branch

4\. Transactions by payment method

5\. Transactions by customer type

6\. Sales by time of day

7\. Distribution of customer ratings

8\. Correlation heatmap of numerical variables

9\. Sales distribution by product line using a box plot



\## Project Files



\- `supermarket\_sales.csv` — Dataset used for analysis.

\- `Supermarket\_Sales\_Visualization.ipynb` — Jupyter Notebook containing the analysis and visualizations.

\- `README.md` — Project documentation.
